# Udacity Machine Learning Bike Sharing Demand Prediction

This is solution of project #1 in Udacity Machine Learning program.

Its goal is to solve regression problem using **Auto Gluon** and [Bike Sharing Demand dataset][https://www.kaggle.com/competitions/bike-sharing-demand].

## Try it yourself

### Requirements

- Python 3
- Git

1. Clone repository into your local machine:
 ```bash
git clone https://github.com/karolcymerys/udacity-machine-learning-bike-sharing-demand
```

2. Go into root of the project:
```bash
cd ./udacity-machine-learning-bike-sharing-demand
```

3. Create new virtual environment (optional):
```bash
python -m venv .venv 
```
